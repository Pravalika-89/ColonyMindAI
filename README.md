# ColonyMindAI 🏡

### AI-Powered Smart Community Management Platform

ColonyMindAI is an intelligent community management platform designed to simplify residential issue reporting, improve communication, and help communities monitor and manage everyday problems.

## 🚀 Features

* 🔐 **User Authentication:** Secure signup, login, and logout.
* 📝 **Issue Reporting:** Submit community issues with descriptions, locations, and priority levels.
* 📊 **Smart Dashboard:** Monitor reported issues and their statuses.
* 🔎 **Advanced Filtering:** Search and filter issues by status and priority.
* 🤝 **Community:** Access the community section.
* 📈 **Smart Insights:** View community issue insights and statistics.
* 🤖 **AI Assistant:** Interact with an AI-powered assistant.
* 🔄 **Issue Management:** Update issue statuses, edit reports, and delete issues.

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Python, Flask
* **Database:** SQLite
* **AI Integration:** Google Gemini API
* **Version Control:** Git and GitHub

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd ColonyMindAI
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

Activate it:

**Windows**

```bash
venv\Scripts\activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure environment variables

Create a `.env` file:

```env
SECRET_KEY=your-secret-key
GEMINI_API_KEY=your-gemini-api-key
```

Replace the placeholder values with your own credentials. Never commit your `.env` file.

### 5. Run the application

```bash
python app.py
```

Open `http://127.0.0.1:5000` in your browser.
